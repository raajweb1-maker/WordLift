# WordLift

WordLift is a professional vocabulary enrichment and writing assistant. It helps writers elevate their language by providing structured, context-aware synonym suggestions categorized for different writing tones.

## Features

- **Smart Dictionary Search**: Integrated with Free Dictionary API for accurate definitions and examples.
- **Global Spellcheck**: Built-in fuzzy matching powered by Datamuse API, ensuring searches for misspelled words automatically resolve to the closest match.
- **Categorized Synonyms**: Automatically categorizes synonyms into Academic, Professional, Poetic, and Common registers.
- **Context Modes**: Interactive features allowing users to see exactly how a synonym changes the tone of a sentence (e.g. Essay Mode, Poetry Mode).
- **Modern UI**: Full Dark Mode support, glassmorphism aesthetics, responsive layouts, and smooth animations powered by Tailwind and Shadcn UI.

## Getting Started

1. Check out the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development environment:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000)

## Deployment

The project is fully ready for deployment on Vercel. 
Push the repository to GitHub, link it on the Vercel dashboard, and the environment will handle everything, including the specific `vercel.json` headers for security.
